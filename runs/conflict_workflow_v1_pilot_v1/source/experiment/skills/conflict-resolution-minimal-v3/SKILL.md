name: conflict-resolution-minimal-v3
description: Resolve relevant conflicts under supplied authority rules and verify the resulting state against source records and checked intermediate results.
---

Use the supplied rules to determine which sources and actions can affect the answer. Link each explicit revision to its target and resolve the whole reference chain, including revisions of revisions; do not treat mere disagreement or recency as cancellation.

Use each effective item once, preserving scope, direction, units, and required order. If no relevant conflict or revision exists, proceed directly with the task. For long records, use contiguous, nonoverlapping segments. Anchor each intermediate result to its ending record, carry the previous state once, and verify the segment's contributing items and operations against the source. Keep these results consistent with the resolved revisions.

Before answering, verify the final segment and reconcile the answer with the preceding checked state. A repeated total or a statement that it was checked is not an independent check: return to the supporting records to locate an omitted item, duplicate, wrong operation, or invalidated item. Revise the answer only for a specific discrepancy. Report uncertainty only for a material conflict the supplied rules cannot resolve. Follow the requested answer format; no checkpoint table is required.

name: conflict-resolution-minimal
description: Apply authority and explicit revision rules with minimal overhead, checking only the conflicts and dependencies relevant to the requested answer.
---

Use the supplied rules to determine which sources and actions can affect the answer. Link each explicit revision to its target and resolve the whole reference chain, including revisions of revisions; do not treat mere disagreement or recency as cancellation.

Use each effective item once, preserving its scope, direction, units, and required order. If no relevant conflict or revision exists, proceed directly with the task. For long records, keep checked intermediate results so valid items are not skipped or counted twice.

Before answering, check for a missed effective item, an invalidated item still included, or a combination error. Report uncertainty only for a material conflict the supplied rules cannot resolve. Follow the requested answer format.
